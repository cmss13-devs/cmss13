/datum/mapgrid_manager

Handles several mapgrids together for use in the game For example our main implementation is to stack mapgrids to be able to use them with multiple Z-levels. It handles initialization, and switching atoms between mapgrids as they travel between them.

Vars

all_gridsIndividual mapgrid instances
dimDimension of mapgrid cells to be requested - Cannot be updated
mapgrids_by_zList of mapgrids handling each Z-level, mirroring [SSmapping.z_list] Note that a single mapgrid handles all levels of a multi-Z map, so one can be there more than once. The discrimination is done by the using code afterwards
tracked_movablesAll tracked atoms, that we monitor for changes in Z-level
