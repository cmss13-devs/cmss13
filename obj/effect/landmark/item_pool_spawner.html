/obj/effect/landmark/item_pool_spawner

These specify locations for a pool of items to be spawned in a random subset of these turfs. They are initialized into one "master" item pool spawner datum. The landmark SS will use that to get these values. Technically only the settings for the last of this pool_name matter.

Vars

mode_flagsIf non-null, limits this item pool to only this game mode
multiplierHow many of type_to_spawn to spawn
pool_nameHolds the UUID of the pool
quotaMax # of items to spawn for the pool.
type_to_spawnThe type or types of item to spawn. If this is a list, it will pick one from that list x multiplier.
